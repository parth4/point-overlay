# The Point

When someone made the point. When they are still circling. When they talk over.

Live: https://parth4.github.io/point-overlay/

This first stop is a static page. Two stretches are tagged. You can paste other YouTube URLs; they are stored in the browser (last 10). They are not tagged yet. Tagging any URL needs a processing engine we have not built.

Economist x Elon is first. All-In is next. Why this stretch sits on the player bar as a hover. Post-process is three layers: Point / Circling / Overlap, then inner emotion, then a short Mediator line (what a calm floor would say). Inner emotion on each person follows the chain of the talk (press, follow, cut, hit, deflect, shift, pin, answer). A landed point is not always a cool-down. Held only while they are talked over, then they return to their last zone. Guess from the talk, not faces. No lecture under the video. Try a few more, then send a link. We mark clips by hand.
