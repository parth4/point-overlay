# Point

When someone made the point. When they are still circling. When they talk over.

Live: https://parth4.github.io/point-overlay/

This first stop is a static page. One All-In stretch is tagged. You can paste other YouTube URLs; they are stored in the browser (last 10). They are not tagged yet. Tagging any URL needs a processing engine we have not built.

- `index.html` — player, panel, paste box
- `cues.json` — timed tags for the All-In stretch

YouTube embed only. Separate from Talentproof. Built with Grok.
